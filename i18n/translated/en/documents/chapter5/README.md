# Dive into LLMs: Model Watermarking

Overview: this part introduces watermarking for language models

> Embedding into language-model-generated content a “watermark” that humans cannot perceive but an algorithm can detect.

## Goals of this tutorial

1. Watermark embedding: embed a watermark while the language model generates content
2. Watermark detection: measure the watermark strength of a given text
3. Watermark evaluation: evaluate the detection performance of the watermarking method
4. Evaluate the robustness of the watermark (optional)



## Preparation

### 2.1 Get to know the X-SIR code repository

https://github.com/zwhe99/X-SIR

The X-SIR repository contains implementations of the following

- Three text watermarking algorithms: X-SIR, SIR and KGW
- Two watermark-removal attack methods: paraphrase and translation

## Hands-on example

> Use the KGW algorithm to embed a watermark in the content generated by a language model

### 3.1 Data preparation

Organize the prompts to be fed to the language model into a jsonl file:

```JSON
{"prompt": "Ghost of Emmett Till: Based on Real Life Events "}
{"prompt": "Antique Cambridge Glass Pink Decagon Console Bowl Engraved Gold Highlights\n"}
{"prompt": "2009 > Information And Communication Technology Index statistics - Countries "}
......
```

- Each line is a JSON object that contains at least a key named “prompt”
- The rest of this tutorial uses `data/dataset/mc4/mc4.en.jsonl` as the example. This file contains 500 entries in total; if the model takes too long to process them, consider trimming the data yourself.

### 3.2 Watermark embedding

- Choose a model and a watermarking algorithm. Here we choose the `baichuan-inc/Baichuan-7B` model and the `KGW` watermarking algorithm

  - ```Shell
    MODEL_NAME=baichuan-inc/Baichuan-7B
    MODEL_ABBR=baichuan-7b
    WATERMARK_METHOD_FLAG="--watermark_method kgw"
    ```

- Generate content and embed the watermark

  - ```Shell
    python3 gen.py \
        --base_model $MODEL_NAME \
        --fp16 \
        --batch_size 32 \
        --input_file data/dataset/mc4/mc4.en.jsonl \
        --output_file gen/$MODEL_ABBR/kgw/mc4.en.mod.jsonl \
        $WATERMARK_METHOD_FLAG
    ```

  - This command saves the model-generated content to the output file: `gen/$MODEL_ABBR/kgw/mc4.en.mod.jsonl`

### 3.3 Watermark detection

> Watermark detection means: given a piece of text, compute its watermark strength (z-score).

- Compute the watermark strength of **watermarked** text

  - ```python
    python3 detect.py \
        --base_model $MODEL_NAME \
        --detect_file gen/$MODEL_ABBR/kgw/mc4.en.mod.jsonl \
        --output_file gen/$MODEL_ABBR/kgw/mc4.en.mod.z_score.jsonl \
        $WATERMARK_METHOD_FLAG
    ```

- Compute the watermark strength of **unwatermarked** text

  - ```python
    python3 detect.py \
        --base_model $MODEL_NAME \
        --detect_file data/dataset/mc4/mc4.en.jsonl \
        --output_file gen/$MODEL_ABBR/kgw/mc4.en.hum.z_score.jsonl \
        $WATERMARK_METHOD_FLAG
    ```

## Evaluating watermark robustness (optional)

> After applying paraphrase and translation attacks to the watermarked text, re-evaluate its detection performance

### 4.1 Preparation

We use the gpt-3.5-turbo-1106 model to apply paraphrase and translation to the watermarked text. You can also choose other tools yourself.

- Set the OpenAI apikey

  - ```Shell
    export OPENAI_API_KEY=xxxx
    ```

- Edit the RPM (requests per min) and TPM (tokens per min) in `attack/const.py`

### 4.2 Run the attack (translation as an example)

- Translate the watermarked text into Chinese

  - ```Shell
    python3 attack/translate.py \
        --input_file gen/$MODEL_ABBR/kgw/mc4.en.mod.jsonl \
        --output_file gen/$MODEL_ABBR/kgw/mc4.en-zh.mod.jsonl \
        --model gpt-3.5-turbo-1106 \
        --src_lang en \
        --tgt_lang zh
    ```

- Re-evaluate

  -  See [3.4](#eval)

- Compare how watermark performance changes before and after the attack
