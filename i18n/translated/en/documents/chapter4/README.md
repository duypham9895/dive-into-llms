# Mathematical Reasoning with LLMs
This project implements code that teaches a large language model (LLM) mathematical reasoning. The main technique is Supervised Finetuning (SFT): the model learns from responses generated by DeepSeek-R1, and from them picks up complex mathematical reasoning skills (such as self-reflection and re-checking calculations).
This lab is based on the [DeepMath-103K](https://huggingface.co/datasets/zwhe99/DeepMath-103K) dataset and the [Qwen/Qwen2.5-Math-1.5B](https://huggingface.co/Qwen/Qwen2.5-Math-1.5B) model, and walks readers through a first attempt at the full data distillation pipeline on math tasks.

## Objectives
- Understand how to clean and preprocess math datasets
- Understand the basic methods for fine-tuning large models
- Understand the basic methods for running inference with large models
- Understand the basic methods for evaluating a model's math ability

## Environment Requirements

- Python 3.8+
- PyTorch
- Transformers
- Datasets
- vllm
- A GPU with at least 40GB of GPU memory

## Lab Guide

1. Open the Jupyter notebook:
```bash
jupyter notebook sft_math.ipynb
```

2. The notebook has several main parts:
   - Dataset download and preprocessing
   - Model loading and training
   - Model generation and evaluation

3. See the notebook for detailed steps and explanations.

## Output Files

Training produces checkpoint files, and the generated results are saved once generation finishes.
